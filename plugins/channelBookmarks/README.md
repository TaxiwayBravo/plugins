# Channel Bookmarks v1.0.0

Cross-server channel bookmarks for Vencord.

## Features

- Right-click any server channel and choose **Bookmark channel**
- Right-click a bookmarked channel and choose **Remove bookmark**
- `/bookmarks` opens all saved channels
- Shows both server and channel names
- **Open** jumps directly to the channel
- **Remove** deletes the bookmark immediately
- Bookmarks are stored locally using Vencord DataStore

No bookmark data is sent to Discord or TaxiwayBravo.

## Install

Install with TaxiwayBravo Plugins Manager, or copy `channelBookmarks` to:

`Vencord/src/userplugins/channelBookmarks`
